FLUVEL - First launch / Premier lancement
=========================================

1. Drag Fluvel Set to the Applications folder.
2. Open Fluvel Set. macOS shows a warning and does not start it:
   this is expected, because the app is not notarized by Apple.
   Close the dialog.
3. Open System Settings > Privacy & Security and scroll down to
   the Security section.
4. Click "Open Anyway" next to Fluvel Set and enter your password.
5. Open Fluvel Set again and confirm.

You only need to do this once. If you do not see the button, open
Fluvel Set once more and check the settings again.
On macOS Sonoma or earlier, you can also right-click Fluvel Set and
choose Open.

------------------------------------------------------------------

1. Glissez Fluvel Set dans le dossier Applications.
2. Ouvrez Fluvel Set. macOS affiche un avertissement et ne la lance pas :
   c'est normal, l'application n'est pas notarisée par Apple.
   Fermez la fenêtre.
3. Ouvrez Réglages Système > Confidentialité et sécurité, puis
   descendez jusqu'à la section Sécurité.
4. Cliquez sur « Ouvrir quand même » à côté de Fluvel Set et saisissez
   votre mot de passe.
5. Ouvrez Fluvel Set à nouveau et confirmez.

Cette opération n'est nécessaire qu'une seule fois. Si le bouton
n'apparaît pas, ouvrez Fluvel Set une nouvelle fois puis revérifiez les
réglages. Sous macOS Sonoma ou plus ancien, vous pouvez aussi faire un
clic droit sur Fluvel Set et choisir Ouvrir.
