Shape Analysis#

This module provides geometric representations and algorithms used for shape comparison and contour analysis.

It includes utilities for converting contour representations, computing geometric properties and evaluating similarity measures such as the Hausdorff distance.

These components are primarily intended for contour validation, benchmarking and shape-based analysis workflows.

References#

Abdel Aziz Taha and Allan Hanbury, An Efficient Algorithm for Calculating the Exact Hausdorff Distance, IEEE Transactions on Pattern Analysis and Machine Intelligence, 37(11):2153–2163, 2015.

class Shape#
#include <shape.hpp>

Geometric shape represented as a set of 2D integer points.

This class is primarily used to represent contour shapes.

It provides basic operations on point sets, such as centroid computation and point shuffling, and serves as the input type for shape-analysis algorithms such as Hausdorff distance evaluation.

class HausdorffDistance#
#include <hausdorff_distance.hpp>

Exact Hausdorff distance between two shapes.

Computes the symmetric Hausdorff distance, max(d(A → B), d(B → A)), with the algorithm of Taha and Hanbury (IEEE PAMI, 2015), which is exact for the maximum:

  • early breaking of the inner loop,

  • random sampling of the points,

  • exclusion of the points shared by both shapes (when coordinates are absolute).

Note

This algorithm discards most of the minimum distances it evaluates. For the mean or the quantiles of these distances, use HausdorffStatistics, which is exact too.

Public Members

bool alignCentroids = {false}#

Align the centroids of both shapes before measuring distances.

When false (default), distances are measured in absolute pixel coordinates, which is the usual definition (MONAI, MedPy, SimpleITK…): a translation between the shapes increases the distance.

When true, every point is expressed relatively to the centroid of its own shape, so only the difference of shape is measured. The translation is available through HausdorffDistance::centroidsDistance().

class HausdorffStatistics#
#include <hausdorff_statistics.hpp>

Exact statistics of the point-to-shape distances of two shapes.

For each point of a shape, the distance to the other shape is the minimum distance to the points of that shape. This class computes all these distances exactly (no early breaking), in both directions (A → B and B → A), and provides:

  • the modified Hausdorff distance (mean of the distances),

  • the quantile Hausdorff distance (e.g. HD95), more robust to outliers than the maximum.

Both values are exact. The algorithm of Taha and Hanbury used by HausdorffDistance cannot provide them, because it keeps only partial minima, which overestimate the mean and the quantiles without any bound.

The cost is O(n × m) for shapes of n and m points, paid once in the constructor; the getters are then cheap.

float quantileDistance(int hundredth) const#

Quantile Hausdorff distance.

The quantile of the minimum distances is taken in each direction with the nearest-rank rule (lower index, ((n - 1) * h) / 100), and the larger of the two is returned. 100 gives the Hausdorff distance, 0 the smallest minimum distance.
