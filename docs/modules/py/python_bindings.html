PyImageArray toImageArray(const py::array &image)#

Validate an image array received from Python and make it contiguous.

Only 8-bit images are accepted (dtype uint8). Supported layouts are:

  • Grayscale: (H, W) or (H, W, 1)

  • Color: (H, W, 3), channels in BGR order

  • Color+A: (H, W, 4), channels in BGR order followed by an unused/alpha channel

Images must have non-zero dimensions.

Arrays that are not C-contiguous (slices with a step, transposed or reversed views such as img[…, ::-1]) are copied.

Parameters:

image – NumPy array to validate.

Throws:

  • py::type_error – If the dtype is not uint8.

  • py::value_error – If the shape is invalid.

Returns:

C-contiguous uint8 array (the input itself when it already is).

void validateSigma(float sigma)#

Validate a Gaussian sigma parameter received from Python.

The Gaussian standard deviation (sigma) must be strictly positive.

Extremely small or large values are accepted and may be clamped internally by the underlying implementation.

Parameters:

sigma – Gaussian standard deviation.

Throws:

py::value_error – If sigma is less than or equal to zero.
