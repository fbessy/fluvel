Python Interoperability#

This module provides the conversion layer between Python objects and the native data structures used by Fluvel IP.

It contains utilities responsible for translating NumPy arrays, contours and other Python-facing representations into their C++ counterparts, and vice versa.

These components form the foundation of the Python bindings while keeping conversion logic isolated from the public API.

Functions

fluvel_ip::ImageView pyArrayToImageView(const py::array_t<uint8_t> &input)#

Convert a NumPy array into an ImageView.

Creates a non-owning view over the memory contained in the provided NumPy array. No pixel data is copied.

The returned ImageView directly references the NumPy array buffer, therefore the array must remain alive for the entire lifetime of the ImageView.

Parameters:

input – Input NumPy array containing image data.

Returns:

Non-owning image view referencing the NumPy array memory.

py::array_t<uint8_t> imageOwnerToPyArray(const fluvel_ip::ImageOwner &image)#

Convert an ImageOwner into a NumPy array.

Allocates a new NumPy array and copies all image pixels into it. The returned array owns its memory independently from the source image.

Parameters:

image – Source image.

Returns:

NumPy array containing a copy of the image data.

fluvel_ip::Shape pyArrayToShape(const py::array_t<int> &contour)#

Convert a NumPy contour array to a Shape.

The input contour must be a 2D NumPy array of shape (N, 2), where each row contains the coordinates of a contour point:

[[x0, y0],
 [x1, y1],
 ...]

Coordinates follow the same convention as Point2D_i:

contour[i, 0] -> x
contour[i, 1] -> y

The resulting Shape contains all contour points and its centroid is computed automatically.

Note

Coordinates are expressed in geometric order (x, y), not image indexing order (row, column).

Parameters:

contour – Input contour as a NumPy array of shape (N, 2).

Throws:

py::value_error – If:

  • the array is not two-dimensional,

  • the array shape is not (N, 2),

  • the contour contains no points.

Returns:

Shape built from the contour points.
