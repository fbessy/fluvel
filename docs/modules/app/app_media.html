Media#

The Media module provides video export infrastructure and media backend integrations used by the Fluvel application.

It defines the generic video export API, export settings and backend abstractions, and provides FFmpeg-based video encoding support when available.

Media Export#

This file defines the public video export API.

The API is backend-independent. Codec and container selection are implementation details.

enum class ExportProfile#

Video export profiles.

A profile represents the intended use of the exported video. The backend automatically selects the most appropriate codec and container for each profile.

Values:

enumerator Archive#

Lossless archival.

Intended for computer vision, scientific work, debugging and long-term storage.

Default backend:

  • Codec: FFV1

  • Container: Matroska (.mkv)

enumerator Compatible#

Maximum compatibility.

Intended for video players, web browsers and video sharing.

Default backend:

  • Codec: H.264

  • Container: MP4

enumerator Balanced#

Balanced quality, size and compatibility.

Intended for everyday use.

Default backend:

  • Codec: H.265

  • Container: MP4

enumerator Efficient#

Best compression efficiency.

Intended for minimizing file size while preserving visual quality.

Default backend:

  • Codec: AV1

  • Container: MP4

enumerator Custom#

User-defined codec and container.

enum class VideoCodec#

Supported video codecs.

The codecs are ordered by their typical usage rather than by their release date.

Values:

enumerator FFV1#

FFV1 lossless codec.

Best suited for scientific image processing and archival. Provides mathematically lossless compression.

enumerator H264#

H.264 / AVC codec.

Excellent compatibility across operating systems, web browsers and media players.

enumerator H265#

H.265 / HEVC codec.

Better compression efficiency than H.264 at the cost of increased encoding complexity.

enumerator AV1#

AV1 codec.

State-of-the-art open video codec providing excellent compression efficiency. Encoding is computationally demanding.

enumerator VP9#

VP9 codec.

Open codec mainly used with the WebM container.

enumerator MPEG4Part2#

MPEG-4 Part 2 Visual codec.

Legacy codec historically used by DivX and Xvid. Mostly kept for compatibility with older software and hardware.

enum class VideoContainer#

Supported video containers.

Values:

Matroska container (.mkv).

enumerator Mp4#

MPEG-4 container (.mp4).

enumerator WebM#

WebM container.

struct VideoExportSettings#
#include <video_export_settings.hpp>

Video export settings.

Defines the parameters used to export a recorded video, including the output file, encoding options and buffering configuration.

Public Members

QString outputPath#

Output path.

In single-file recording mode, this is the path of the exported video.

In circular recording mode, this is the directory (or base path, depending on the implementation) where the recording segments are stored.

RecordingMode recordingMode = {RecordingMode::SingleFile}#

Recording mode.

Defines how the recording is stored.

  • RecordingMode::SingleFile records everything into a single file.

  • RecordingMode::Circular records successive video segments and automatically removes the oldest ones according to the retention settings.

int retentionTimeMinutes = {30}#

Total retention time.

In circular recording mode, the oldest recording segments are automatically removed so that approximately this amount of video history is preserved.

Expressed in minutes.

Ignored in single-file recording mode.

int segmentCount = {10}#

Number of recording segments.

The retention time is divided into this number of segments.

Larger values produce shorter segments, while smaller values produce longer segments.

Ignored in single-file recording mode.

int fps = {30}#

Target frame rate.

Specifies the frame rate written to the exported video. This value should normally match the acquisition frame rate.

ExportProfile profile = {ExportProfile::Archive}#

Export profile.

Fluvel is primarily a computer vision application; therefore, Archive is the default profile. When set to Custom, the codec and container specified below are used.

VideoCodec codec = {VideoCodec::FFV1}#

Video codec.

Used only when profile is set to ExportProfile::Custom.

VideoContainer container = {VideoContainer::Matroska}#

Video container.

Used only when profile is set to ExportProfile::Custom.

RecordingBufferSettings bufferSettings#

Recording buffer configuration.

Defines the buffering strategy used during recording, including RAM limits, temporary storage limits and overflow handling.

enum class ExportState#

Internal state of the exporter.

The exporter is initially closed. Calling open() starts a new export session but defers the FFmpeg initialization until the first frame is received. Once initialized, frames can be encoded until close() is called.

Values:

enumerator Closed#

No export session is active.

enumerator WaitingForFirstFrame#

Waiting for the first frame to determine the output format and to initialize FFmpeg.

enumerator Recording#

Export session initialized and ready to encode frames.

Describes an available FFmpeg video codec.

A codec is considered available when:
